# Quick Start Guide

## 5-Minute Setup

### 1. Prerequisites
```bash
# Check Java installation
java -version
# Output should show Java 11 or higher

# Check Maven installation
mvn -version
# Output should show Maven 3.8.9 or higher
```

### 2. Clone/Navigate to Project
```bash
cd d:\Testing\ in\ AI\DemoWebShopAutomation
```

### 3. Install Dependencies
```bash
mvn clean install
```
